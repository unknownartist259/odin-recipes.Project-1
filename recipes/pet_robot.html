The Desk Pet Robot

Build your own tiny desktop companion with animated eyes that blink, express emotions, and react to your computer activity.

Ingredients

  • Seeed Studio XIAO ESP32-S3 microcontroller
  • 0.96-inch SSD1306 OLED display
  • Female-to-female jumper wires
  • USB-C cable
  • 3D-printed robot enclosure
  • PLA filament
  • Hot glue
  • Soldering iron
  • Cutter
  • Arduino IDE
  • Python and required libraries

Instructions

  1. Prepare the electronics: Connect the microcontroller and OLED display, then test the animated eyes.
  2. Bake the body: 3D-print the robot enclosure using PLA filament.
  3. Assemble the robot: Solder the display connections and secure the components inside the enclosure.
  4. Bring it to life: Upload the robot firmware and configure its Wi-Fi connection.
  5. Connect the computer: Run the Python client to detect computer activity and send updates to the robot.
  6. Serve your creation: Test the different moods, including music, typing, browsing, and idle mode.
