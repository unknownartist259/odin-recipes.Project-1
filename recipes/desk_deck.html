The Desk Pet Robot

Create a minimalist desk gadget that displays your currently playing Spotify song, artist, album cover, date, and weather on a low-power e-Paper screen

Ingredients

  • Raspberry Pi 4
  • 2.7-inch Waveshare e-Paper display
  • Home Assistant
  • Spotify developer account and API credentials
  • Python
  • Pillow (PIL) imaging library
  • Requests library
  • Waveshare e-Paper Python library
  • Webhook utility
  • Fonts and album artwork

Instructions

  1. Prepare the workstation: Set up the Raspberry Pi and connect the e-Paper display
  2. Configure the music source: Set up Home Assistant and integrate Spotify
  3. Create the trigger: Configure an automation that detects when the current song changes
  4. Set up the messenger: Create a webhook endpoint on the Raspberry Pi to receive automation requests
  5. Gather the ingredients:Use Python to retrieve song details, artist information, album artwork, and weather data through Home Assistant's API
  6. Prepare the layout: Use Pillow to draw the text, weather information, and album cover onto an image
  7. Plate the resultRender the completed image on the e-Paper display and put the display to sleep to save power
  8. Taste your creation:Play different songs and verify that the display updates when the track changes
